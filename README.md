# 🍕 Pizza Sales Dashboard Analysis (Python | Jupyter Notebook | Power BI)

## 📌 Summary
An end-to-end data analysis project that explores pizza sales data using Python for analysis and Power BI for interactive dashboard visualization.

---

## 📖 Project Overview
This project focuses on analyzing pizza sales data to uncover meaningful business insights such as total revenue, best-selling pizzas, order trends, and customer purchasing patterns.  
Python (Jupyter Notebook) is used for data cleaning and analysis, while Power BI is used to create an interactive and visually appealing dashboard.

---

## ❓ Problem Statement
The pizza store wants to understand:
- Which pizza categories and sizes generate the most revenue
- Sales trends by day and month
- Average order value and pizzas per order
- Overall performance metrics to support business decision-making

---

## 📂 Dataset
- **File Name:** `pizza_sales.csv`
- **Description:** Contains detailed pizza order data including order date, pizza name, category, size, quantity, and price.
- **Records:** Multiple orders across different dates and categories
- **Source:** Publicly available dataset (used for learning and analysis)

---

## 🔍 Methods Used
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Aggregations & Grouping
- KPI Calculations:
  - Total Revenue
  - Total Orders
  - Total Pizzas Sold
  - Average Order Value
  - Average Pizzas per Order
- Data Visualization using Power BI

---

## 📊 Key Insights
- Total Revenue generated: **~817K**
- Total Orders: **~21K**
- Total Pizzas Sold: **~50K**
- **Classic** pizza category contributes the highest sales
- **Large (L)** size pizzas are the most frequently ordered
- Highest number of orders observed on **weekends**
- Monthly trends show peak sales during specific months

---

## 📈 Dashboard / Output
- Interactive Power BI dashboard with:
  - KPI cards
  - Sales by category & size
  - Daily and monthly order trends
  - Slicers for month, day, pizza size, and category

📌 **Dashboard File:** `pizza dashboards.pbix`  
(Note: GitHub does not preview `.pbix` files. Download and open in Power BI Desktop.)
